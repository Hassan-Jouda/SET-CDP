يفحص HTTPS و Security Headers ويعطي Security Score.

🔒 SSL Inspector

يفحص شهادة SSL وتاريخ الانتهاء والجهة المصدرة.

🔑 Password Strength Analyzer

📧 Email Phishing Detector
